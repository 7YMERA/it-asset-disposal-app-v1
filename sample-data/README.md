# Sample data

Made-up records in the same shape as the app's main SharePoint lists. All names, emails, serial numbers
and asset tags are fictional; device models are real products so the dropdowns make sense.

To rebuild the backend in your own SharePoint site, create a list for each file with the same column
names, then import the CSV. See [the data model](../docs/data-model.md) for how the lists relate.
